DATA FLOW: LOGIN
═══════════════════════════════════════════════════════════════════════════════

  1. User types email + password in Login.tsx
                    ↓
  2. Form submission calls useAuth().login()
                    ↓
  3. POST /api/auth/login { email, password }
                    ↓
  4. Express receives request
                    ↓
  5. Find user in MongoDB by email
                    ↓
  6. Bcrypt compares password hash
                    ↓
  7. If match: Generate JWT token
                    ↓
  8. Return token + user data
                    ↓
  9. AuthContext saves token to localStorage
                    ↓
  10. useAuth().isAuthenticated = true
                    ↓
  11. Navigate to /profile (protected route works now)
                    ↓
  12. Header shows username + logout button

TROUBLESHOOTING TREE
═══════════════════════════════════════════════════════════════════════════════

  Issue: Can't connect to MongoDB
  └─ Solution: Run `mongod` (local) or check Atlas whitelist

  Issue: npm run test:db fails
  └─ Solution: Check MONGODB_URI in .env

  Issue: Seed script doesn't create users
  └─ Solution: Verify MongoDB connection first with `npm run test:db`

  Issue: Login page doesn't work
  └─ Solution: Restart dev server after MongoDB starts

  Issue: Token not persisting
  └─ Solution: Check browser localStorage (DevTools → Application)
